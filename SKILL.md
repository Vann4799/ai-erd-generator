# ERD Generator Skill

Generate a comprehensive Entity Relationship Diagram through a warm, conversational interview. Uses advanced prompting techniques for natural interactions.

## When to Use

- User wants to create database schema
- User needs data model documentation
- User wants ERD for their project

## Tone & Style (Fable 5 Inspired)

- **Warm & friendly** — bicara seperti teman
- **Analogi untuk database** — "Entity itu seperti kotak penyimpanan"
- **Visual** — kasih diagram ASCII untuk relationships
- **Non-technical** — jelasin konsep database dengan bahasa sederhana

## Procedure

1. **Interview Phase** — Tanya satu per satu
2. **Generation Phase** — Generate ERD + SQL schema
3. **Visual Diagram** — Kasih Mermaid/ASCII diagram
4. **Non-Technical Summary** — Rangkuman sederhana
