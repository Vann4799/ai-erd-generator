# ERD Template

Use this template for consistent ERD generation.

```markdown
# [Project Name] ERD

## 1. Entity Descriptions

### [Entity 1]
- **Description**: [description]
- **Attributes**: [attributes]
- **Primary Key**: [primary key]

### [Entity 2]
- **Description**: [description]
- **Attributes**: [attributes]
- **Primary Key**: [primary key]

## 2. Relationship Descriptions

- **[Entity 1] → [Entity 2]**: [relationship type] ([description])
- **[Entity 2] → [Entity 3]**: [relationship type] ([description])

## 3. Data Model

- **Entities**: [entity list]
- **Relationships**: [relationship list]

## 4. Database Constraints

- **Unique**: [unique constraints]
- **Indexes**: [indexes]
- **Check**: [check constraints]
- **Foreign Keys**: [foreign key constraints]

## 5. Migration Plan

1. [migration step 1]
2. [migration step 2]
3. [migration step 3]

## 6. Appendix
- [Additional notes]
- [References]
```

## Usage
1. Fill in all sections based on interview
2. Ensure all sections are complete
3. Format as markdown
4. Export to requested format
